# 更新日志

本文档记录了HotKey Go Client的所有重要变更。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
并且本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.2.0] - 2024-08-14

### 新增
- **启动工具包**: 新增独立的 `startup` 包，提供生产级启动管理API
- **事件驱动启动**: 支持详细的启动阶段跟踪和事件订阅机制
- **多种等待策略**: QuickWait、HealthCheck、GracefulWait三种启动策略
- **Context支持**: 完整的context.Context集成，支持优雅取消操作
- **启动工具包文档**: 新增 `startup/README.md` 详细文档
- **使用示例**: 新增 `examples/using_startup_package.go` 启动工具包使用示例
- **优化总结**: 新增 `examples/OPTIMIZATION_SUMMARY.md` 启动优化总结文档

### 改进
- **启动优化**: 所有示例文件摆脱硬编码 `time.Sleep()`，使用智能健康检查
- **用户体验**: 丰富的emoji日志输出和详细的进度反馈
- **错误处理**: 更优雅的错误处理和降级策略
- **文档完善**: 更新主README文档，添加目录、故障排除等章节
- **测试增强**: 新增启动相关的测试用例和基准测试

### 修复
- **日志导入冲突**: 修复了 `etcd/starter.go` 和 `network/client.go` 中的日志包导入冲突
- **编译错误**: 解决了 `undefined: log` 等编译错误
- **日志调用**: 统一了自定义日志包和标准库日志的使用方式

### 技术改进
- **性能优化**: 动态等待时间（100ms-30s），避免资源浪费
- **可靠性提升**: 基于实际状态的健康检查机制
- **监控完善**: 详细的启动状态和连接监控
- **代码质量**: 更规范的导入和调用方式

## [1.1.0] - 2024-08-13

### 新增
- **增强日志系统**: 多级别日志支持，支持文件输出和多重日志器
- **全局上下文管理**: 统一的配置和状态管理
- **精细化缓存控制**: 灵活的缓存构建器，支持多种配置选项
- **事件驱动架构**: 基于事件总线的异步事件处理机制

### 改进
- **网络通信**: 与Java版本完全兼容的Protostuff网络通信协议
- **配置中心集成**: 与etcd配置中心集成，支持动态配置和热更新
- **本地缓存管理**: 基于Ristretto的高性能本地缓存

## [1.0.0] - 2024-08-12

### 新增
- **初始版本**: HotKey Go客户端首次发布
- **热Key自动探测**: 智能收集应用中的key访问信息，批量推送到worker节点分析
- **本地缓存**: 高性能本地缓存，自动存储热key
- **Java兼容**: 与现有Java版本Worker节点无缝互通
- **基础示例**: 提供基本使用和高级使用示例

### 功能
- 支持热key探测和本地缓存
- 支持与etcd配置中心集成
- 支持与Java Worker节点通信
- 提供全局API和实例API两种使用方式
